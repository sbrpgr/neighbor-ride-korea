# 교통취약지역 주민 보유 차량의 이동 지원 자원화

등록제 기반 자가용 유상운송의 자원 규모와 비용효율 분석(전국 230개 시군구 통계·전남 곡성군 적용)
「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」(2026) 분석보고서의 코드·원자료 저장소

- 보고서: [`report/김대운_분석보고서.pdf`](report/김대운_분석보고서.pdf), 한글 원본 [`report/분석보고서.hwpx`](report/분석보고서.hwpx)
- 검증 기록: [`report/verification.md`](report/verification.md)

## 핵심 결과

| 구분 | 결과 |
|---|---|
| 차량 자원 | 인구감소지역 92곳 인구 1천 명당 자가용 승용차 422대(전국 403대) |
| 의료 접근 격차 | 병·의원 평균 접근시간 대중교통 43분, 승용차 11분(시군구 중앙값) |
| 택시형 대비 | 주민차량 1회 공공지출 1% 절감(빈차 귀가)~38% 절감(동행 왕복) |
| 신규 차량 투입(DRT) 대비 | 면 단위 수요에서 69~85% 절감, 손익분기 연 8,028회 |
| 곡성군 적용 | 택시 1대 이하 7개 면에서 연 5.3~6.0억 원 절감 |
| 해외 운영 | 일본 865개 단체·6,307대, 전체 시정촌의 39% 운영(2026. 3.) |

- 모든 수치의 출처: `data_clean/*_results.json`

## 실행

```bash
pip install -r requirements.txt
python code/run_all.py          # data_raw → data_clean → figures → report/cells → 검증
python code/80_build_hwpx.py    # (선택) 한컴오피스 설치 PC에서 양식 조판·PDF 변환
python code/90_verify.py --urls # (선택) 활용 데이터·저장소 URL 접속 점검
```

- `run_all.py` 2회 실행 시 결과 파일 해시 비교 결과를 `report/verification.md`에 기록

## 주요 가정(민감도 분석 대상)

- 차량실비: 「교통시설 투자평가지침」 승용차 차량운행비용(40km/h) 중 감가상각 제외, 유류비는 2026. 1.~9. 평균 휘발유가로 환산
- 수고보상: 2026년 최저임금 × 소요시간(평균 속도 40km/h, 승하차 10분)
- 운행보험: 금융감독원 공개 단체 On-Off형 특약 10분당 178원 × 2(승객 위험 가중)
- 안전교육·점검 연 5만 원, 운전자 1인 연 120건, 정산비 건당 500원
- 평균 편도거리: 곡성 효도택시 운행당 지출을 완주군 택시운임 고시에 대입해 역산(8.4km)

## AI 활용

- Anthropic Claude Code(Claude Opus 5.5)로 수집·정제·분석·그림·조판 코드 작성
- 해외 사례·비용 원단위 조사는 하위 에이전트가 수행, `docs/`에 출처 기록
- 모든 수치는 스크립트가 원자료에서 재계산하고 원문 문자열과 대조

## 이용 조건

- 원자료 저작권은 각 제공기관에 있음, 공공데이터포털 자료는 이용허락범위 제한 없음
- 분석 코드·원고: 출처 표시 조건으로 자유 이용 가능
